## Color Tokens

- Iron Black `#0f0e0d`
- Golden Glow `#e8bd79`
- Warm Earth `#de865b`
- Surface `#1c1814`

## Rules

- Prefer the SVG versions for the site.
- High-contrast mono versions for laser/merch.
- Never stretch or apply soft effects.
